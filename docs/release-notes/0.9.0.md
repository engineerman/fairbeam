# Fairbeam 0.9.0

Fairbeam 0.9.0 (engineerman fork) adds an **opt-in** experimental [EMerge](https://github.com/FennisRobert/EMerge)
frequency-domain FEM path beside the default openEMS FDTD solver. openEMS remains the production
default. These notes describe the source tree tagged as v0.9.0 (`85c63180`); this fork does not
yet publish a separate desktop installer, and the upstream Fairbeam updater is disabled so an
upstream install cannot wipe the EMerge integration.

## Opt-in EMerge FEM

- **Install EMerge** (Windows managed venv, pinned `emerge==3.0.0b12`; optional path /
  `FAIRBEAM_EMERGE_PYTHON` elsewhere) from Simulation → Experimental solvers.
- **Session engine picker** on the Simulation ribbon chooses **EMerge (experimental)** or
  openEMS and retargets Run chrome, Frequency / Boundaries / Mesh settings, and which actions
  stay enabled.
- **One Run entry — EMerge FEM · Experimental:** admits driven/lumped or planar microstrip
  Designs with **1–8 ports of one type** and exports a full experimental N×N S-matrix
  (`fairbeam.emerge-result/2`). Status is `results_exported`, never a validated production
  certificate. Geometry remains bounded; unsupported shapes are rejected rather than silently
  remapped (`accept_*` gates on approximate maps).
- **Mesh without solve**, FEM exterior-surface overlay in Mesh view, mid-plane E-field cuts,
  and a Design port→boundary-condition preview.
- Fixed WR-90 waveguide fixture remains available for analytic checks.

## Documentation and fork policy

- Document the setup and limits in [experimental solvers](../EXPERIMENTAL-SOLVERS.md) and
  [EMerge experiment](../EMERGE-EXPERIMENT.md).
- README New features covers the picker, Install, and N-port Run; About credits EMerge.
- Upstream `fairbeam-releases` automatic updates are **disabled** in this tree.

## Release scope and remaining qualification

EMerge does not claim openEMS S-parameter agreement. Completing Install or a run does not
establish numerical accuracy for a given Design. Far-field / gain certificates are out of scope
on this path. Multilayer, vias, curves, mixed port types, and other rejected geometry stay
deferred. Source tags and local builds do not establish installer, installed-runtime, upgrade,
or live-updater success for a fork-specific desktop release — none is published yet.
