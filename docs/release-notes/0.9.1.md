# Fairbeam 0.9.1

Fairbeam 0.9.1 (engineerman fork) adds the **Filter designer** for planar hairpin microstrip
bandpass synthesis, plus product documentation in English and Turkish. These notes describe the
source changes after v0.9.0; this fork still does not publish a separate desktop installer.

## Filter designer

- Start-menu **filter-designer** product tile opens a three-step wizard:
  Topology → Parameters → Preview.
- **Parameters** edits order, center frequency, bandwidth, filter type, port impedance, and
  stack-up (dielectric constant, substrate thickness, loss tangent), with a live theoretical
  `|S11|` / `|S21|` plot and a microstrip stack sketch.
- The S plot is an **ideal J-inverter network** preview — **not an openEMS result**. Caption in
  the UI states the same. Real EM comes after Finish, via the normal Simulation path.
- **Preview** commits **Closed form** dimensions immediately, or an optional **EDC** (EM design
  curves) study that builds `Qe` / `k` from small electromagnetic sweeps. Finish opens the layout
  as a new Design; further tuning uses Sweep / Optimizer. The wizard does not run a full-filter
  openEMS solve for a measured final S certificate.

## Release scope and remaining qualification

Ideal S and Closed form are synthesis aids, not solver certificates. EDC refines seed dimensions
with bounded studies; it does not replace a full-filter EM run on the committed Design. Filter
designer does not change the openEMS default or the experimental status of EMerge. Source tags
and local builds do not establish installer, installed-runtime, upgrade, or live-updater success
for a fork-specific desktop release — none is published yet.
